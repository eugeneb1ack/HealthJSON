# Health JSON: руководство пользователя

Health JSON создаёт личный снимок данных Apple Health на iPhone. Приложение работает с тремя независимыми путями: файл JSON для автоматизированных интеграций, CSV для таблиц и прямая доставка по приватной сети Tailscale.

## Первый запуск

1. Откройте приложение и нажмите **Разрешить доступ к Здоровью**. HealthKit показывает системный список доступных категорий; приложение получает только разрешённые для чтения данные.
2. В разделе **Экспорт** нажмите **Выбрать папку iCloud Drive** и выберите личную папку в iCloud Drive. Приложение создаст в ней каталог `Health JSON`. Если выбранная папка уже называется `Health JSON`, она используется как готовый корень без вложенного дубликата.
3. Нажмите **Обновить данные** и дождитесь статуса «Снимок обновлён». Первый снимок за год может занять несколько минут. Экран остаётся рабочим, а последующие обновления быстрее.

## Какие файлы создаются

В выбранной папке появляются:

- `Health JSON/Agent/health-context.json` — полный, компактный снимок последних 365 дней. Это канонический формат для API, агентов и скриптов.
- `Health JSON/Agent/health-context.csv` — тот же актуальный снимок в плоском CSV для Numbers, Excel, LibreOffice и pandas. Сложные записи сохраняют подробности в колонке `details_json`.
- `Health JSON/Agent/Inbox/health-update-*.json` — короткие трёхдневные обновления для резервной доставки и диагностики.
- `Health JSON/Exports/.../*.json` — технический по-типовый архив HealthKit. Он предназначен для отладки, а не для повседневного чтения в таблице.

Каждый публичный файл полного обновления заменяется атомарно: приложение сначала создаёт новый файл и только потом заменяет прежний. JSON — канонический снимок; если запись CSV не удалась, прежний JSON остаётся нетронутым. Пустой ответ HealthKit не может затереть непустой текущий JSON-снимок.

## JSON и CSV

В переключателе **Формат для «Поделиться»** выберите JSON или CSV. По нажатию **Поделиться** приложение всегда сначала создаёт свежий полный снимок, затем открывает системное меню отправки выбранного формата.

Автосинхронизация и прямой API всегда используют JSON. CSV не заменяет JSON: в CSV теряются типы и вложенная структура, которые необходимы приёмнику для корректной идемпотентной обработки.

## Автосинхронизация и батарея

Переключатель **Автоматическая синхронизация** не запускает постоянный таймер. Приложение подписывается на изменения HealthKit через `HKObserverQuery`, объединяет несколько изменений максимум на пять минут и использует фоновое окно iOS только когда оно предоставлено системой. Ежедневный полный снимок нужен, чтобы забрать поздние исправления источников HealthKit.

Для экономии батареи:

- оставляйте автосинхронизацию включённой, если нужны свежие данные — событийная схема экономнее ручного частого запуска;
- не нажимайте «Обновить данные» несколько раз подряд: одно обновление уже ждёт завершения текущего;
- не держите Tailscale включённым только ради этого приложения, если вам достаточно iCloud Drive;
- в приложении одновременно выполняется не более восьми тяжёлых HealthKit-запросов; один неответивший запрос прерывается по тайм-ауту и не блокирует снимок навсегда.

## Tailscale и другое приложение

Настройка находится в **Tailscale и API**. Она выключена при первом запуске и не требуется для сохранения в iCloud. Если прямая доставка выключена или Mac недоступен, актуальные JSON и CSV всё равно появляются в iCloud, а неотправленное API-обновление остаётся в защищённой очереди iPhone. Введите адрес вашего приёмника Tailscale: можно вставить URL, который показал `tailscale serve`, без пути. Приложение добавит путь `/health-json/v1/import`, сохранит адрес только на этом iPhone и позволит его в любой момент заменить или удалить. Очередь привязана к конкретному адресу, поэтому старые обновления не уйдут на новый Mac после смены URL.

Для приложения-получателя используйте один из двух контрактов из [INTEGRATION.md](INTEGRATION.md): приватный HTTPS API через Tailscale или чтение точного файла из iCloud Drive. Не считывайте временные файлы и не обрабатывайте iCloud-конфликты как новые снимки.

## Конфиденциальность

- HealthKit не сообщает приложению, какие разрешения на чтение отклонены: отсутствие показателя не доказывает отсутствие данных.
- Данные в выбранной папке iCloud Drive являются обычными JSON и CSV файлами. Защитите Apple ID, устройства и доступ к папке.
- Прямая доставка ограничена tailnet Tailscale; приложение не публикует данные в интернете.
- Клинические FHIR-записи намеренно не запрашиваются. Маршруты тренировок, ЭКГ и пульсовые серии могут содержать особенно чувствительные данные — делитесь ими осознанно.
